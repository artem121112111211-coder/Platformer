# Platformer

# Installation

1. **Install Python 3.14.7** (make sure the version matches).
2. **Install dependencies**: open your terminal in the repository folder and run **pip install -r requirements.txt**

# Run

1. Open your terminal in the repository folder and run **python main.py**
